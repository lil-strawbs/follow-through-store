# Follow Through World Clock

A live, responsive digital clock showing the current time across major cities and time zones. Built with vanilla HTML, CSS, and JavaScript so it can be deployed directly to GitHub Pages.

## Features

- Live local time and date
- Nine preloaded global cities
- Search cities and time zones
- Add additional cities from the built-in selector
- Responsive card layout
- No build step or dependencies required

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

Enable GitHub Pages for the `main` branch in the repository settings. The site will use the browser's `Intl.DateTimeFormat` API to calculate time-zone-aware times.
